Privacy

Your files stay on your machine.

Onley is a local duplicate-file tool. It does not create an account, show ads, or collect telemetry.

What Onley reads

Onley reads the folders you select and the local index at ~/.onley/local.db. It stores file paths, sizes, modification times and MD5 hashes in that index so later scans can skip unchanged files.

Network access

Onley does not contact a server during normal scanning or cleanup. It uses the network only when you explicitly run a network feature such as serve or replica, or when you choose to download an update or open a link. The desktop client does not check for updates automatically.

Deletion

Deletion is permanent and local. Onley shows the exact files and asks for confirmation before removing them. Files changed since the scan are skipped.

Third-party components

The desktop client is built with NSGo, licensed under Apache 2.0. See THIRD_PARTY_NOTICES.md for notices.

Contact

Questions or privacy concerns can be raised at github.com/fdaio/onley/issues.

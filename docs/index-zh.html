Onley 以字节级精度扫描本地存储，找出重复组、比较文件哈希并释放被浪费的空间。桌面应用只在你确认后删除，普通扫描全程留在本机。

为什么选择 Onley？

小工具，清晰决策。

默认本地运行

索引保存在 ~/.onley/local.db。隐私内建：无遥测、无云端、无需账号。

断点续扫

随时取消。已完成的文件保留在索引中，下次扫描会跳过未变化的文件。固定大小的 worker 池让 CPU 占用可预期。

保留最新或最旧

按修改时间在每组中保留最新或最旧的副本；时间相同时按路径排序。

为高级用户打造
提供命令行界面。

命令行优先

在终端中扫描、检查并清理，工作流可脚本化，速度快。

字节级比较

Onley 按内容哈希比较文件，而不只是文件名，因此重命名后的副本仍能匹配。

低资源占用

使用 Go 编写，固定大小的 worker 池与本地 SQLite 索引。

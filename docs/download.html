macOS, Linux and Windows · CLI binaries are unsigned

The macOS desktop app is the validated build. The Windows and Linux desktop packages build and package, but have not been run yet. On Windows, SmartScreen may warn, and Smart App Control can block unsigned apps.

Onley is distributed directly from GitHub Releases, not through the App Store, Google Play or Microsoft Store. It is desktop-only; there is no iOS, Android or TV app.

Why Onley

Small tool. Clear decisions.

Local by default

The index lives at ~/.onley/local.db. Onley has no telemetry and no account.

Resume scans

Cancel at any time. Finished files stay indexed, and the next scan skips unchanged files.

Newest or oldest

Keep the newest or oldest copy in every group by modification time. Equal times fall back to path order.

Confirm before delete

The desktop client reviews the exact files first. It checks size and modification time and skips files that changed since the scan.

Desktop and CLI

Use the native client for review, or the CLI for scan, dupes, clean, stats and watch.

English and 中文

The interface follows the system language and switches with one button. The choice is remembered.

How it works

Three steps, one confirmation.

  1. Scan. Add one or more folders. The live gauge shows hashing speed.
  2. Review. Pick a copy to keep in every group, or apply the newest/oldest policy.
  3. Delete. Confirm the exact files. The desktop client verifies them before removing the rest.

Install

Get Onley

macOS

The app is signed with a Developer ID and notarized by Apple.

brew tap laotree/tap
brew install --cask onley

Direct download · Apple silicon and Intel

Windows

Download the desktop zip or the CLI from the latest release.

onley-desktop_*_windows_x64.zip

Windows code signing is in progress.

Linux

Download the desktop tarball or the CLI from the latest release.

tar -xzf onley-desktop_*_linux_x64.tar.gz

Linux packages are not code signed yet.
